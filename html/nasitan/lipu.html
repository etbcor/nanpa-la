Downloads

There are three versions:

  • The "main" version,
    which converts Latin characters into Sitelen Pona
  • The "Unicode" version,
    in which there is only Sitelen Pona, via this spec
  • The "Helvetica" version,
    which uses Helvetica's name so that vanilla Discord picks it up

      • Previous versions can be found on this page.

What is it?

At first, all it's glyphs were wack. But with the help of many friends, I've worked hard toward the goal of creating an accessible and featureful font for sitelen pona!

It uses this specification.
